# วิธีใช้ FPGA Ecosystem (สำหรับผู้ช่วย AI — app_help ค้นทีละหัวข้อ)

## ภาพรวมโปรแกรม
FPGA Ecosystem มีหน้าหลัก (Home) และ Schematic Studio (ตัววาดวงจรเกต) สำหรับบอร์ด EDGE Spartan-7 (XC7S15)
ขั้นตอนทำงานเรียงตามแถบด้านบนของ Schematic Studio: วาด → เลือกขา → จำลอง → ลงบอร์ด
หนึ่งโปรเจกต์มีได้หลายแผ่น (sheet) แผ่นหนึ่งใช้อีกแผ่นเป็นบล็อกได้ (วงจรแบบลำดับชั้น) แผ่นที่มีดาว ★ คือแผ่นบนสุด (top) ที่จะลงบอร์ด
โปรเจกต์เก็บในโฟลเดอร์ Documents/FPGA Ecosystem/Projects บันทึกด้วย Ctrl+S และมีประวัติย้อนเวลา (ปุ่ม 🕘)
Ctrl+K เปิดช่องค้นหาคำสั่งทั้งหมด พิมพ์ไทยหรืออังกฤษก็ได้

## วาดวงจรด้วยมือ
ลากชิ้นส่วนจากแถบซ้าย (Components: AND, OR, NOT, XOR, NAND, NOR, XNOR, D-FF, JK-FF, INPUT, OUTPUT, VCC/GND) วางบนแผ่น
ต่อสายโดยลากจากขาหนึ่งไปอีกขาหนึ่ง เครื่องมือ ≣ (กด B) ลากจากพอร์ตหลายบิตเพื่อสร้างบัส คลิกสายบัสเพื่อวาง Bus Tap แยกบิต
ล้อเมาส์หรือ Space+ลาก เลื่อนจอ, Ctrl+ล้อ ซูม, Del ลบ, F7 ตรวจวงจร
ปุ่ม 🧹 จัดสายใหม่ทั้งแผ่น, โหมด 🧲 วางชิ้นส่วนแล้วให้โปรแกรมเดินสายให้
ชื่อของ INPUT / OUTPUT จะเป็นชื่อพอร์ตใน VHDL ตั้งเป็นเลขต่อท้าย เช่น q0..q3 แล้วรวมเป็นบัส q[3:0] ได้ที่ Tools ▸ รวมขาเป็นบัส

## คลังชิ้นส่วนและโมดูล
Tools ▸ คลังชิ้นส่วนและโมดูล (หน้าต่างคลัง) แบ่งหมวดตามหน้าที่ มีช่องค้นหา
ชิ้นส่วนสำเร็จ (part) เลือกแล้วตั้งค่า เช่น จำนวนบิต, bus, blocks แล้วกด "วางเป็นบล็อก" ลงแผ่นที่เปิดอยู่ หรือ "เปิดเป็นแผ่นใหม่"
ทุกชิ้นส่วนถูกสร้างจากโค้ดและตรวจเทียบกับแบบจำลองอ้างอิงก่อนวาด แผ่นที่ผ่านจะมีตรา ✓ ตรวจแล้ว (หายเมื่อแก้)
ชิ้นใหญ่สร้างเป็นลำดับชั้นจากชิ้นย่อยที่ตรวจแล้ว เช่น bcd_counter_multi ประกอบจาก counter_digit
"โมดูลของฉัน" = แผ่นที่ผู้ใช้บันทึกไว้ใช้ข้ามโปรเจกต์ (บันทึกได้เมื่อแผ่นผ่านการตรวจ) มีเวอร์ชัน อัปเดตสำเนาในโปรเจกต์ได้
บล็อก VHDL สำเร็จรูป (บวก/ลบ/คูณ/หาร, 7-seg, LCD, ADC, UART, เสียง) อยู่ในหมวดเดียวกัน ตั้งค่าแล้ววางได้เลย ขาของบอร์ดถูกแมปให้
หมวด "เครื่องมือออกแบบ" = ตัวสร้างวงจร (ตารางความจริง/K-map, ตัวนับ, หารความถี่, FSM, shift register …)

## ประกอบวงจรใหญ่จากหลายบล็อก
แนวทาง: แตกงานเป็นบล็อกย่อย → หาแต่ละบล็อกจากคลัง (หรือวาดเองเป็นแผ่นย่อย) → วางทุกบล็อกบนแผ่น top → ต่อสายตามชื่อขา
ตัวอย่างนาฬิกา/ตัวนับบนจอ 7-seg: หารความถี่ 50 MHz ลงมาเป็นจังหวะนับ (divider_chain หรือ clock_divider) → edge_detector ทำเป็น tick 1 clock
→ ตัวนับต่อหลัก (counter_digit หลายตัว ต่อ tc ของหลักหน่วยเข้า en ของหลักถัดไป หรือ bcd_counter_multi ทีเดียว)
→ seg7_mux4 (สแกน 4 หลัก a–g / an active-low ของบอร์ด EDGE) ต่อเข้า 7-seg
ปุ่มกดต้องผ่าน debounce หรือ one_pulse ก่อนใช้เป็นสัญญาณควบคุม
แลป 6 และแลป 7 มีเป็นระบบทั้งแลป (lab6_counter, lab7_countdown) ดูวิธีต่อเป็นตัวอย่างได้
Inspector มีปุ่ม 💡 แนะนำการต่อสายของขาที่ยังว่าง (cout→cin, ชื่อขาเดียวกัน)

## ตารางความจริง สมการ และ K-map
Tools ▸ ตารางความจริง / K-map: กรอกตาราง → ย่อสมการ (Quine–McCluskey) → วาดวงจรให้และตรวจครบทุกแถว
ในแชตโหมด "วาดวงจร" พิมพ์สมการได้เลย เช่น sum = a xor b หรือมินเทอม y = minterms(1,2,4,7)
Inspector ▸ 📋 ดูตารางความจริง ของชิ้นส่วนที่เลือก

## ข้อกำหนดและการตรวจวงจร (spec)
ไม่มีอะไรเลือก → Inspector มีกล่อง "ข้อกำหนด" ตั้งเป็นสมการ ตาราง หรือลำดับ clock แล้วโปรแกรมตรวจซ้ำทุกครั้งที่แก้ (✓/✗ ในแผนผังโปรเจกต์)
F7 / แท็บ Issues แสดงปัญหา: ขาลอย สายมีหลายตัวขับ เกตที่ไม่ได้ใช้
Tools ▸ เทียบวงจรสองแผ่น ใช้เทียบวงจรของผู้ใช้กับชิ้นส่วนอ้างอิง

## FSM
Tools ▸ ออกแบบ FSM: พิมพ์ state diagram เป็นข้อความ เช่น
inputs: x / state S0: z=0 / S0 -> S1 when x / else / reset S0 (Mealy เขียน / z=1 หลังเงื่อนไข)
โปรแกรมเข้ารหัสสถานะ ย่อ logic ใช้ D-FF และตรวจทีละ clock กับ diagram ก่อนวาด

## บล็อก VHDL ที่เขียนเอง
Tools ▸ บล็อก VHDL (เขียนโค้ด): เขียน entity + architecture หนึ่งชุด ขาของบล็อกมาจาก port
ตัวจำลองในโปรแกรมรองรับ: signal, constant, enum / array (ROM), process + if / case / for, rising_edge, when-else, with-select, numeric_std, std_logic_unsigned
ไม่รองรับ: port map ข้างใน, wait, generate, inout, สัญญาณกว้างเกิน 32 บิต
ปุ่ม "ตรวจโค้ด" แจ้ง error พร้อมบรรทัด บล็อก VHDL ใช้ได้ทุกโหมดจำลองยกเว้นเล่นเวลาจริง

## เลือกขา (pin) บนบอร์ด EDGE
แท็บ "เลือกขา": แมปแต่ละพอร์ตไปสวิตช์ SW0–15, LED 0–15, ปุ่ม pb0–4, จอ 7-seg (a–g, dp, an0–3), clk 50 MHz, LCD, VGA, UART …
pin_preset ตามแลป (6/7/8) ช่วยตั้งให้ทั้งชุด จอ 7-seg และ an เป็น active-low (0 = ติด) ปุ่มกด = 1 เมื่อกด
หมอบอร์ด 🩺 (หน้าลงบอร์ด) ตรวจขาซ้ำ ขาที่ยังไม่แมป 7-seg ผิดขั้ว clock จากปุ่มกด และมีปุ่ม 🔧 แก้ให้

## จำลอง
แท็บ "จำลอง": บอร์ดจำลอง + ตารางความจริง + ไทม์มิ่ง กดสวิตช์บนบอร์ดจำลองได้ วงจรมี clock ใช้ "ก้าว 1 clock"
⚡ เล่นเวลาจริง (50 MHz) เมื่อพอร์ตแมปกับ clk ของบอร์ด: ดู LED / 7-seg ทำงานจริง
บนแผ่นวาดมีโหมดจำลองสด (probe) และปุ่ม ⏭ 1 clk ใต้ขา clock
ผลไม่ตรง → 🩺 ทำไมผลไม่ตรง? (หน้าจำลอง) อธิบายสาเหตุ: clock, reset ค้าง, สายขาด, ลืมตัวหารความถี่

## ลงบอร์ด
แท็บ "ลงบอร์ด": Vivado สร้าง .bit จากแผ่น top (1–3 นาที) แล้ว openFPGALoader โหลดลง FPGA ผ่าน USB
ต้องติดตั้ง Vivado และไดรเวอร์ USB (หน้า Home ▸ เริ่มต้นใช้งาน ตรวจให้) โหลดลง SRAM หายเมื่อปิดไฟ เขียน Flash ถาวรได้จากหน้านี้
บอร์ดทำงานไม่เหมือนจำลอง → ปุ่ม "บอร์ดไม่ทำงานเหมือนที่จำลอง?" ไล่ถามอาการ

## แชต AI ในโปรแกรม
แชตใน Schematic Studio มี 3 โหมด: วาดวงจร (พิมพ์ชื่อวงจรหรือสมการ แล้ววาด+ตรวจให้), ถาม-ตอบ, เอเจนต์ (โมเดลสั่งเครื่องมือเอง)
"นี่วงจรอะไร" ในแชตอธิบายแผ่นที่เปิดอยู่โดยไม่ใช้โมเดล
